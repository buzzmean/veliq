# VELIQ

VELIQ — приложение для Windows, которое выбирает маршрут для отдельных соединений. Оно использует прямой доступ, локальные сетевые стратегии и, когда это предусмотрено правилами сервиса, защищённое соединение через сервер VELIQ.

[Скачать для Windows](https://veliqapp.ru/download) · [Личный кабинет](https://veliqapp.ru/account) · [Поддержка](https://veliqapp.ru/support)

## Как работает VELIQ

Приложение определяет процесс и назначение соединения. Для доступного ресурса сохраняется прямой маршрут. При проблемах с доступом применяются предусмотренные для этого соединения стратегии. Уже установленные соединения сохраняют свой маршрут: смена правил действует на новые подключения.

- **Прямой маршрут** — соединение с ресурсом без сервера VELIQ.
- **Локальная стратегия** — обработка соединения на компьютере пользователя, без пересылки игрового трафика через релей.
- **Защищённый маршрут** — соединение через сервер VELIQ с проверкой устройства и сертификатов. Используется для сервисов, которым разрешён такой маршрут.
- **AUTO** — автоматический выбор в пределах правил приложения и назначения. Ручные настройки профиля сохраняются.

Для игр применяются прямой маршрут и локальные стратегии. Игровой релей в текущей версии не используется. Наличие ответа сервера или загрузка карты сами по себе не подтверждают успешный вход в игру. Результат зависит от конкретной игры, сервера и сети; снижение задержки без измерений не заявляется.

Служба Windows выполняет перехват и маршрутизацию. Окно VELIQ работает без прав администратора и управляет службой через канал с проверкой доступа. Сервер управления выдаёт подписанные настройки и разрешения; пользовательский трафик через него не проходит. Для защищённых сервисов сохраняется запрет на переход к прямому соединению при отказе защищённого маршрута.

## Установка и обновление

Установщик и номер последней опубликованной версии доступны на [странице загрузки](https://veliqapp.ru/download). Обновление сохраняет активацию, настройки и профили. Загруженный пакет проверяется по подписанному манифесту и SHA-256. Подробности подготовки и восстановления: [установщик без перезагрузки](docs/INSTALLER_NO_RESTART.md).

В клубе компьютер подключается к подписке по коду или через подтверждение в личном кабинете. Личная подписка и клубная активация не требуют повторной активации после обычного обновления.

## Сборка

Требуются Go 1.25, .NET SDK 8 и компилятор C для проверок с `-race`. Для работы с захватом нужна Windows 10/11 x64 и закреплённый комплект WinDivert. Версию и контрольные суммы драйвера нельзя заменять произвольно: [описание зависимости](docs/WINDIVERT_DEPENDENCY.md).

```sh
go build ./...
go test -race -timeout 120s ./...
go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build ./...
dotnet test tests/desktop --nologo
```

Сборка интерфейса на Windows:

```powershell
& .\tools\windows\build-desktop.ps1
```

Сборка под Windows на другой ОС проверяет компиляцию. Она не подтверждает работу захвата, интерфейса или подключения к реальному игровому серверу. Для тестов с PostgreSQL нужна отдельная тестовая база; команды и требования приведены в [документации сервера управления](CONTROL_PLANE.md).

## Ограничения

- Сетевой захват ориентирован на IPv4. Поддержку IPv6 нельзя считать полной.
- VELIQ не расшифровывает HTTPS и не устанавливает сертификат для подмены содержимого соединений.
- Данные о задержке до контрольной цели не заменяют измерения до конкретного игрового сервера.
- Неизвестный процесс или неполное наблюдение не доказывают применение стратегии.
- Успешная сборка и автоматические тесты не означают успешную проверку на всех провайдерах, играх и версиях Windows.

При обращении в поддержку укажите версию VELIQ, имя компьютера, время сбоя и приложение. Не публикуйте ключи, коды активации, токены, сертификаты устройства и исходные захваты трафика.
