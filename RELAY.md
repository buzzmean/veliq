# Сервер защищённого транспорта

Релей VELIQ принимает разрешённые соединения клиента и передаёт их к назначению. Сервер управления не участвует в пересылке данных. Для игровых соединений текущая версия VELIQ релей не использует.

## Разработка

```sh
go run ./tools/lab
docker compose up --build -d
```

Первая команда запускает временный стенд UDP/TCP с взаимной проверкой сертификатов. Вторая поднимает окружение разработки с обязательными билетами. Параметры отдельного сервера:

```sh
go run ./services/relay/cmd/relay -help
```

Для защищённого запуска нужны сертификат и ключ сервера, доверенный CA устройств, идентификатор релея, доверенные ключи подписи билетов и постоянный файл защиты от повторного использования. Адрес сервера управления и отдельный токен используются для обновления состояния. Отсутствие обязательного ключа или состояния не должно разрешать авторизацию.

## Ограничения и наблюдение

Стандартный UDP-порт — 4433. Проверка состояния и метрики доступны на `127.0.0.1:9090`. Политика назначения отклоняет частные, локальные, служебные и специальные адреса. Разрешённые сети и правила брандмауэра задаются явно. Лабораторные исключения нельзя переносить в открытый рабочий сервер.

Число сессий, потоков, размеры очередей и скорость пакетов ограничены. Состояние использованных билетов сохраняется между запусками. Разрешённая сессия действует ограниченное время; публикация конфигурации и отзыв проверяются независимо от пересылки пакетов.

Метрики отражают активные сессии и потоки, число UDP-пакетов и TCP-соединений, байты, отбросы, отклонённые потоки и ошибки авторизации. Работа экспортёра не доказывает доступность сервера из сети клиента: её проверяют отдельные измерения.

Защита инфраструктуры от DDoS, пропускная способность и качество через публичный интернет требуют самостоятельной приёмки.
