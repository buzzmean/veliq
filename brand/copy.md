# VELIQ — тексты

Единый источник текстов для сайта, программы, установщика и материалов. Тексты в макетах (`app-ui/`) и на сайте (`website/`) взяты отсюда.

## Позиционирование

Говорим общо и о пользе, а не об устройстве:

- **Не называем** число серверов, их города и имена, число ПК в клубах, конкретных клиентов.
- **Не рекламируем доступ к заблокированным ресурсам** и обход блокировок: в России реклама таких средств запрещена, а платёжные сервисы отключают такие магазины. Говорим о пользе: быстрый путь для игр, стабильная связь для голосовых чатов, стримов и других онлайн-сервисов. Не называем конкретные сервисы как «открывающиеся».
- Слова, которых нет на сайте, в рекламе и в описании для платёжных сервисов: «обход блокировок», «разблокировка», «заблокированные сервисы», «VPN» (в том числе «не VPN», «отличие от VPN»), «прокси», «анонимность», «скрыть IP», «смена региона», названия сервисов как «открывающихся». Вместо них: маршрут, задержка, пинг, потери, стабильность, собственная сеть серверов.
- Описание должно оставаться правдивым: VELIQ направляет часть соединений через свои серверы — это говорим прямо (оферта, политика, «Что видит сервер»).
- **Про игры** — только «VELIQ выстраивает оптимальный маршрут / самый быстрый путь». Не пишем «игры идут напрямую» и не называем конкретные игры в обещаниях.
- **Не обещаем** конкретный пинг. Цифры — только как иллюстрация с пометкой или как замер в программе.
- Внутри программы можно показывать имя текущего сервера и замеры — это состояние, а не реклама.
- **На сайте и в материалах** — только общая информация: не называем сторонние системы (системы управления клубами и т. п.), технический режим, образы, пароль администратора, трей, время запуска, размер файла, расположение серверов и устройство продукта. Подробные инструкции — в вики.

## Слоган

**У свободы свой маршрут.**

Первый экран: «У свободы» / «свой маршрут.» — две строки. Подпись: «VELIQ подбирает маршруты для игр, общения и работы в интернете. Каждому соединению — свой путь.»

Фирменная оранжевая линия изображает маршрут под заголовком. Движение плавное и однократное; при уменьшении анимации в системе линия статична.

## Описание

**Одно предложение.** VELIQ сам выстраивает оптимальный маршрут для каждого соединения: игры получают самый быстрый путь, голосовые чаты и стримы — стабильную связь.

**Абзац.** VELIQ — программа для Windows, которая сама выбирает путь для каждого соединения. Для онлайн-игр — самый быстрый маршрут до сервера, для голосовых чатов, стримов и других онлайн-сервисов — самый стабильный, в том числе через собственную сеть серверов. Всё, что и так работает хорошо, остаётся как есть. Достаточно нажать одну кнопку.

**Для клубов.** Быстрый путь для игр и стабильная связь на всех компьютерах клуба. Гостю ничего настраивать не нужно.

## Тон

- На «вы», просто, коротко. Глаголы действия.
- Ошибка = что случилось + что сделать. Без извинений, без «упс», без «что-то пошло не так».
- Кнопка называет действие, и результат называется тем же словом: «Оптимизировать» → «Работает»; «Закрепить» → «Закреплено»; «Обновить» → «Обновлено».
- Никаких технических слов в интерфейсе для гостя: не «релей», «PAC», «WinDivert», «QUIC». В диагностике — можно, но с пояснением.

## Игры: режимы

Подсказка экрана: «Выберите режим для игры. Пинг VELIQ пока не замеряет, поэтому режим «Через VELIQ» может его увеличить.»

| Режим в службе | Название | Описание |
|---|---|---|
| AUTO | Авто | VELIQ сам решает для каждого соединения игры. |
| DIRECT | Обычный | Игра работает как без VELIQ. Режим по умолчанию. |
| DIRECT_PLUS | Обычный + | Обычный путь с улучшением игрового трафика. Для игр без такой поддержки: «Для этой игры пока недоступно.» |
| MANUAL (RELAY) | Через VELIQ | Весь трафик игры идёт через сервер VELIQ. Пинг может вырасти. |

- Античит Vanguard или FACEIT: «Совместимость с античитом … не проверена. Сами игру не трогаем — режим меняется только по вашему выбору.» Остальные: «Снижение пинга пока не измерено. По умолчанию игра идёт обычным путём.»
- После «Применить»: «Сохранено: <режим>. Действует для новых соединений игры — если матч уже идёт, изменения подхватятся в следующем.»
- Лаунчер Riot Client: «Если лаунчер не запускается или не обновляется, VELIQ подберёт для него путь. Режим игры и античит не меняются.» Кнопка «Исправить лаунчер» → «Лаунчер настроен. Запустите игру, чтобы проверить.»
- Клубный ПК: «Настройками клуба управляет администратор. Режимы игр на этом компьютере меняет администратор клуба.»
- Служба не отвечает: «Служба VELIQ не отвечает. Каталог открыт, но режимы сейчас не сохранить. Закройте VELIQ и откройте заново.»

## Предупреждения и уведомления

| Событие | Заголовок | Текст |
|---|---|---|
| Включилось | VELIQ работает | Маршруты построены. |
| Сервер сменился | Сервер не отвечает — работаем через другой | Всё работает, задержка может быть выше обычной. Вернёмся сами, когда сервер заработает. |
| Связь потеряна | Связь с сервером потеряна | Перестраиваем маршрут через другой сервер. Это займёт пару секунд. |
| Связь вернулась | Связь восстановлена | Маршруты снова оптимальные. |
| Есть обновление | Доступна версия X.Y | Обновление установится без перезапуска браузера и займёт около минуты. |
| Игра: найден путь быстрее | Найден путь быстрее на N мс | Новый маршрут применится к следующему матчу, текущий не прерывается. |

## Как установить (3 шага)

Общая подача, без технических подробностей. Подробные инструкции и скриншоты — в вики VELIQ (готовится).

1. **Получите код активации.** Для клуба он выдаётся после заявки, для игрока — отдельно.
2. **Установите VELIQ.** Установщик сам сделает всё нужное, дополнительных шагов не требуется.
3. **Введите код активации.** После этого VELIQ готов к работе.

Для клубов есть отдельная инструкция, она выдаётся вместе с кодом активации.

## Вопросы и ответы

**Как VELIQ выбирает путь?** Программа замеряет задержку и потери до сервера игры или сервиса и выбирает лучший путь: обычный — через провайдера, или через собственные серверы VELIQ, если так быстрее или стабильнее. Всё, что и так работает хорошо, не трогает.

**Нужно ли что-то перезапускать?** Нет. Маршруты работают сразу, ничего закрывать и перезапускать не нужно.

**Как VELIQ влияет на пинг в играх?** VELIQ сравнивает пути до игрового сервера и выбирает самый быстрый. Если путь через сеть VELIQ не быстрее обычного, маршрут не меняется. Замеры видно в программе.

**Вы видите, что я открываю?** Нет. Мы не расшифровываем и не подменяем HTTPS. Сервер видит адрес назначения и объём данных — этого достаточно, чтобы переслать трафик. Точный список — в политике конфиденциальности.

**Какие системы поддерживаются?** Сейчас VELIQ работает на компьютерах с Windows. Версия для телефона готовится.

**Подходит ли VELIQ для клубов?** Да. Для клубов есть отдельный код активации и инструкция, они выдаются после заявки.

**Подходит ли VELIQ для моей системы управления клубом?** Напишите нам, подскажем.

**Как выключить?** Нажмите большую кнопку ещё раз. Интернет продолжит работать как без программы.

**Как добавить свой сайт или приложение?** Вкладка «Сервисы» → «Добавить». VELIQ подберёт для него маршрут так же, как для остальных.
