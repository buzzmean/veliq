# Дизайн VELIQ

Единый дизайн сайта, Windows-программы и материалов. Всё выведено из логотипа: чёрно-белая геометрия, контур буквы Q и прорезь с сигнальной линией `#F0502A`, которая значит «маршрут построен».

**Что открыть первым:** `app-ui/index.html` (кликабельная программа), затем `website/index.html` (сайт) и `design/index.html` (дизайн-система).

## Структура

```
design/
  index.html            дизайн-система: принципы, тон, логотип, цвет, шрифт, сетка, иконки, движение, компоненты
  tokens/tokens.json    токены — единственный источник (цвета светлой и тёмной темы, шрифт, отступы, радиусы, тени, движение)
  tokens/tokens.css     те же токены в CSS-переменных (генерируется)
  components.css        общие компоненты: кнопки, большая кнопка, переключатели, сегменты, поля, карточки, статусы,
                        метки, таблицы, модальные окна, уведомления, полосы трафика, графики пинга, схема маршрута
  charts.js             график пинга без зависимостей
  icons/sprite.svg      39 иконок; icons.js — тот же набор для вставки в страницу (генерируется)
  fonts/                Onest (переменный, кириллица + латиница, 48 КБ), лицензия OFL
  tools/                build-tokens.py, build-site.py, render-assets.mjs, make-ico.py
website/                сайт: index, download, clubs (с калькулятором), pricing, support, privacy, terms, 404,
                        sitemap.xml, robots.txt, site.webmanifest, assets/
app-ui/                 макеты программы: index.html (все экраны и состояния, трей, мини-окно, режим клуба),
                        installer.html (установщик), app.css, app.js
brand/                  логотип, иконки, баннеры, OG-картинка, тексты, презентация для клубов — см. brand/README.md
```

## Как посмотреть локально

Шрифты браузер грузит только по http, поэтому открываем через простой сервер (Python есть на большинстве ПК):

```bash
cd <папка репозитория>
python -m http.server 8080
```

Затем в браузере:
- http://localhost:8080/app-ui/ — программа
- http://localhost:8080/website/ — сайт
- http://localhost:8080/design/ — дизайн-система

Двойным кликом файлы тоже открываются, но вместо Onest будет системный шрифт.

В макете программы слева — панель для переключения экранов и состояний. Адрес хранит состояние: `app-ui/index.html#games/on//`, `#home/error/relay/`, `#club/on//`, `#home/on//update` — удобно давать ссылку на конкретный экран.

Активация — пятая часть адреса: `#home/off///act-code` (ввод кода), `act-busy`, `act-done`, `act-change` (смена кода), `act-err-ACTIVATION_LIMIT` (любая ошибка по коду службы), `#settings/on///act-expiring` (скоро истекает). Каталог игр — `#games/on///`; в панели макета есть варианты «служба не отвечает» и «клубный ПК». Тексты — `brand/copy.md`, разделы «Активация» и «Игры: режимы».

## Ссылки из программы на помощь

У каждой ошибки на странице помощи постоянный адрес — кнопка «Подробнее» в программе может открывать сразу нужный ответ (страница сама раскроет его):

| Ошибка | Адрес |
|---|---|
| VELIQ не может запуститься | `support.html#err-service` |
| Нет связи с сервером | `support.html#err-relay` |
| Часть сайтов не открывается | `support.html#err-browser` |
| Код активации не принят | `support.html#err-identity` |
| Не хватает прав | `support.html#err-rights` |

Ключи совпадают с кодами ошибок в `app-ui/app.js`. Новую ошибку добавлять в `ERRORS` и `ERR_IDS` в `design/tools/build-site.py`.

## Как менять

| Что | Где | Потом |
|---|---|---|
| Цвета, шрифт, отступы | `design/tokens/tokens.json` | `python3 design/tools/build-tokens.py` |
| Компоненты | `design/components.css`, `design/charts.js` | `python3 design/tools/build-tokens.py` |
| Тексты сайта, версия, домен, почта | `design/tools/build-site.py` (словари `SITE`, `RELEASE`) | `python3 design/tools/build-site.py` |
| Стили сайта | `website/assets/site.css` | — |
| Иконки, баннеры | `brand/icons/*.svg`, `brand/social/*.html` | `node design/tools/render-assets.mjs`, `python3 design/tools/make-ico.py`, `build-tokens.py` |

`build-tokens.py` копирует токены, компоненты, шрифт, иконки и логотипы в `website/assets/`, `app-ui/assets/`, `design/assets/` — поэтому каждая папка самостоятельна и публикуется отдельно.

## Решения

- **Стек сайта — чистый HTML/CSS/JS без сборщика:** открывается где угодно, публикуется на любой статический хостинг (GitHub Pages, Cloudflare Pages), грузится мгновенно. Главная со стилями и скриптами — около 80 КБ без сжатия, шрифт — 48 КБ.
- **Любые экраны:** телефон от 320 px, планшет, ноутбук, монитор; от 1680 px шире контейнер, от 2200 px страница масштабируется (до ×2 на 4K-телевизоре), фокус для пульта крупнее. Проверено скриншотами на 320, 768, 1024, 1366, 1920, 2560 и 3840 px — без горизонтальной прокрутки и ошибок.
- **Доступность:** все пары текста по контрасту не ниже WCAG AA, видимый фокус, переход к содержимому, навигация с клавиатуры, Esc закрывает меню и окна, учитывается «уменьшить движение», состояние никогда не передаётся только цветом.
- **SEO:** title, description, canonical, Open Graph, Twitter card, JSON-LD (SoftwareApplication, FAQPage), sitemap, robots, manifest.
- **Позиционирование** — общее (см. `brand/copy.md`): без числа серверов и ПК, сервисы — как примеры, для игр — «оптимальный маршрут».
- **Чужие логотипы** (YouTube, Discord и т. д.) не используются — вместо них монограммы.

## Допущения (проверить и заменить)

1. **Домен сайта** `veliq.app` — заглушка; фактический HTTPS origin ещё требуется подтвердить. Почта поддержки `support@veliqapp.ru` выбрана владельцем. Адреса меняются в `build-site.py` (`SITE`), затем пересборка. Почтовый домен сам по себе не определяет адрес сайта/API.
2. **Версия, дата, размер и ссылка на установщик** — заглушки в `build-site.py` (`RELEASE`). SHA-256 вписать при выпуске.
3. **Цены** не указаны — страница `pricing.html` намеренно заготовка.
4. **Политика конфиденциальности и условия** — черновики, нужна проверка юриста; срок хранения журналов на сервере не указан.
5. **Функции из макетов, которых ещё нет в программе:** режим клуба с паролем администратора, «Оптимизировать при запуске», счётчик маршрутов, мини-окно трея, отчёт диагностики. Это предложения по интерфейсу, а не описание текущего кода. Экран активации и каталог игр (24.10.2026) нарисованы по текущему коду: состояния и коды ошибок службы, `GameCatalog.json`, режимы AUTO / DIRECT / DIRECT_PLUS / MANUAL, кнопка «Исправить лаунчер» для Riot. Допущения: «Обычный +» доступен только играм с UDP-пресетом (сейчас Dota 2 и PUBG); срок активации в настройках — по дате сертификата, без технических названий.
6. **Клубы и откат:** если образ с VELIQ раздаётся на все ПК, у всех может оказаться одинаковый ключ устройства. Нужно решение в коде (выдавать ключ при первом запуске или хранить вне образа) — тексты на сайте этого не обещают.
7. **Английский:** в программе переключатель языка работает для меню, главного экрана и настроек; остальные строки пока только на русском. Сайт на английском не сделан — структура готова (`lang`, `og:locale`), нужна папка `website/en/`.
8. В шапке сайта и в материалах файлы логотипа переименованы `veliq3-*` → `veliq-*`; содержимое не менялось.

## Отложено по решению владельца (21.10.2026) — не трогать без его команды, но не забыть

1. Главная, список «Ускоряет»: «Игровые серверы в Европе — доступ и низкий пинг». Предложение: «Закрытые игровые серверы — доступ и низкий пинг».
2. Описание главной для поисковиков заканчивается «Для Windows 10 и 11». Предложение: убрать для единообразия с «Бета-версией».
3. Текст политики конфиденциальности: «сервер-релей», порт, SNI, «журнал диагностики» и «отчёт диагностики» (отчёта в программе, вероятно, ещё нет). Проверить при передаче политики юристу.

## Шрифт для программы (WPF)

WPF не поддерживает WOFF2 и переменные шрифты, поэтому для программы в `design/fonts/static/` лежат статические начертания Onest в TTF (400 Regular, 500 Medium, 600 SemiBold, 700 Bold, 800 ExtraBold), латиница и кириллица. Сделаны из исходного переменного шрифта Google Fonts (OFL, лицензия рядом). Семейство во всех файлах — `Onest`.
