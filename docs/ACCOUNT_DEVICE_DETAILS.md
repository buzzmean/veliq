# Компьютеры в личном кабинете

Кабинет показывает имя Windows, версию VELIQ, последний подтверждённый контакт и подпись места. Подпись места принадлежит аккаунту и не заменяет настоящее имя ПК. Если старый клиент ещё не передал сведения, имя и версия не угадываются.

## Передача сведений

Служба читает имя через `os.Hostname()` и передаёт сведения не чаще одного раза в минуту. Сначала она проверяет поддержку метода сервером. Сервер без этого метода не получает новые сообщения; повторная проверка выполняется через 15 минут. Работа завершается при отмене контекста подключения.

`POST /api/v1/device/details` принимает подписанное сообщение устройства. Назначение подписи содержит SHA-256 от передаваемых сведений. Изменение тела, просроченная подпись, повтор одноразового значения и отзыв устройства не допускают обновления. Запись сведений и использование одноразового значения выполняются в одной транзакции с блокировкой устройства.

Сервер не принимает произвольный идентификатор другого ПК от личного кабинета. Подпись места изменяется отдельно через сеанс владельца подписки; проверяются аккаунт, подписка и единственное соответствующее место.

## Состояние связи

«На связи» означает свежий подтверждённый контакт не старше трёх минут. Для клиента, который передавал сведения и затем перестал отвечать, сервер может показать отсутствие связи. Старый неподдерживаемый клиент без свежего подтверждения имеет неизвестное состояние.

Время последнего контакта относится к связи службы с сервером управления. Оно не доказывает исправность игрового подключения, захвата или всех маршрутов.

## Коды и история

Выпуск нового кода использует существующий метод подписки. Он меняет код для новых подключений и сохраняет уже занятые места. Ограничения подписки, проверки клуба и пробного доступа сохраняются.

Исторические подписки и завершённые платежи не удаляются. Отменённый платёж без спорного статуса не получает кнопку повторной проверки. Возвраты и споры остаются видимыми.

Кнопка сообщения о проблеме заполняет черновик обращения именем и версией ПК. Сообщение отправляется только пользователем.
