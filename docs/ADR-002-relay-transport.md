# ADR-002: транспорт защищённого соединения

Выбран QUIC через quic-go: TLS 1.3, постоянные авторизованные сессии, ненадёжные DATAGRAM для UDP и отдельный двунаправленный канал для каждого TCP-потока.

| Вариант | Преимущества | Издержки |
|---|---|---|
| QUIC | Готовый стек TLS, мультиплексирование, поддержание NAT, ненадёжные датаграммы | Управление перегрузкой и служебные данные требуют измерений |
| WireGuard | Эффективный защищённый транспорт L3 | Нужно добавить управление потоками и классификацию приложений |
| Собственный шифрованный UDP | Возможны небольшие накладные расходы | Самостоятельная защита от повторов, управление ключами, перегрузкой и NAT не оправданы для первого этапа |
| Туннель TCP | Совместимость с распространёнными сетями | Блокировка очереди между потоками ухудшает поведение UDP |

Собственная криптография не разрабатывается. Взаимная проверка сертификатов устройства дополняется короткоживущими подписанными билетами, привязанными к ключу устройства и конкретному релею. UDP не переводится в надёжный поток как резервный вариант. Перегрузка и ограниченные очереди могут приводить к отбросу датаграмм.
