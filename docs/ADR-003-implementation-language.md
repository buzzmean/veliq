# ADR-003: язык реализации

Для ядра, релея и сервера управления выбран Go 1.25. Он предоставляет HTTP, TLS, проверку гонок и интеграцию с quic-go, а также сборку под Windows и Linux.

Rust даёт безопасность памяти без сборщика мусора и более точное управление выделениями, но увеличивает стоимость первоначальной реализации и взаимодействия через FFI. Смену языка следует обосновывать измерениями текущей реализации.

Будущий драйвер WFP потребует совместимого с WDK кода C/C++, изолированного за интерфейсом сетевого слоя. Постоянное состояние хранится в PostgreSQL. Отдельный Redis для этого решения не требуется.
