# Бренд VELIQ: состав и проверка

Публичное имя продукта — VELIQ. Утверждённые исходные SVG импортированы из коммита `2dfdb483e15abf7a0714347c973647b2c38b31f1`. Их геометрия, цвета и пропорции сохраняются; имя файла не является разрешением перерисовывать знак.

| Поверхность | Требование |
|---|---|
| Заголовок окна, меню, трей и уведомления | VELIQ, русский текст, достоверное состояние |
| Установщик, ярлыки и пакет | Имя VELIQ и согласованная версия |
| Логотип | Утверждённый словесный знак или символ для соответствующего фона |
| Значки Windows и трея | Экспорт утверждённого знака с проверкой малых размеров |
| Пользовательские каталоги и служба | Канонические имена текущего установщика VELIQ |
| Сайт и документация | Русский текст без исторического тестового бренда |
| Технические компоненты | Последовательные имена VELIQ; изменение совместимости проверяется отдельно |

## Исходники изображений

Символ, инверсный символ и словесные знаки для тёмного и светлого фона находятся в `assets/brand` и `brand`. В WPF используются соответствующие пути, преобразования и прорезь. SVG не должен содержать сценарии, внешние ресурсы или дополнительные шрифты.

Чёрно-белый интерфейс, клавиатурный фокус и отключённые элементы должны сохранять читаемость. Импорт изображения не доказывает, что значок установщика, панели задач и трея корректно выглядит при разных масштабах экрана.

## Совместимость

Старые технические идентификаторы ещё встречаются в исходном коде. Их полное удаление требует согласованного изменения протоколов, сборки и переноса существующей установки. Этот документ не объявляет такую миграцию выполненной.

Обновление обязано сохранять идентичность устройства, владельца, ключи, профили, настройки и данные восстановления браузера. Чужие ярлыки, настройки и автозапуск не заменяются. Браузеры ради оформления не закрываются.

Проверяются исходные SVG и SHA-256, сборка WPF, ресурсы, нативный вид окна и значков, установка поверх прежней версии и возврат при ошибке. Ни один из этих результатов сам по себе не подтверждает все остальные.
