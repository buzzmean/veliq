# Подключение игровых клиентов через системный прокси

Windows использует общий пользовательский HTTP-прокси. Его могут учитывать
Steam, CS2 и другие приложения, даже когда их профиль выбран «Напрямую».
Ранее обычный прямой запрос проходил отдельный этап DNS с лимитом1секунда
и одним заранее выбранным IP. По умолчанию это системный DNS; дополнительный
лимит и отсутствие альтернатив адреса могли сорвать обычный Windows TCP.

Для профиля DIRECT без дополнительных правил, обязательного fallback,
временной области или локальной стратегии используется штатный net.Dialer:
обычный системный resolver и выбор доступных IPv4/IPv6-адресов. Браузерное
обучение, повтор первого запроса, TLS-преобразования и автоматический relay
к такому подключению не добавляются. Это выбор адреса до отправки данных,
а не перенос установленного игрового соединения.

У общего обработчика AUTO и профилей с правилами DNS также использует
оставшийся общий трёхсекундный бюджет планирования. Дополнительного секундного
отказа перед проверкой политики больше нет. Адресная и доменная политика,
в том числе обязательный relay для защищённого сервиса, сохраняется.

Владелец PID/birth/SID и текущий профиль повторно проверяются после DNS,
перед каждым исходящим соединением. Защищённая authority и свежая связь
адреса с защищённым доменом не получают DIRECT. AUTO, MANUAL, BLOCK,
профили с правилами и отдельный принятый путь CS2 AUTO сохраняются.
Перехват игровых UDP-пакетов, anti-cheat и существующие потоки не меняются.

Регрессии проверяют отказ отдельного DNS, доступную альтернативу адреса,
реальный server-first TCP и неизменные бинарные данные, изменение владельца
или профиля до SYN, защищённые authority/адреса. Отдельный native Windows
тест проходит полный authorityPlan → authorityOpen на настоящем PID/SID
для профилей Steam, CS2 и другой игры. Используются только loopback и
профили в памяти; ОС, служба, системный прокси и игры не изменяются.

Лабораторные результаты не устанавливают причину конкретного зависания
Counter-Strike. Для этого нужны фактические версия, профиль, стадия
соединения и успешный первый вход в сеть игры на проверяемом ПК.
