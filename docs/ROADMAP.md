## Цель релиза (Definition of Done)

Клуб в Ставрополе, ~40 ПК, бездисковая система Langame (откат при перезагрузке).

1. Один установщик `VELIQ-Setup.exe`, один клубный код на все ПК, установка в образ без ручных шагов на каждом ПК.
2. Гость включает ПК → VELIQ уже работает: без диалогов, перезагрузок, перезапуска браузеров, ручных добавлений.
3. Заблокированные сайты и сервисы работают: YouTube, Discord, Telegram, ChatGPT, Claude, Instagram и т.п.; обычные сайты (VK, Яндекс) — напрямую без задержек.
4. Игры: PUBG (обход UDP без VPS), Riot/Valorant (Vanguard), FACEIT — запускаются и играются, античиты не ругаются.
5. Экономия: всё, что обходится локально (DPI/SNI/QUIC), идёт DIRECT/LOCAL на ПК; через VPS — только блокировки по IP/гео-блок. Цель — трафик VPS на клуб укладывается в тариф (Hostkey 3 ТБ/мес) с запасом.
6. Отказоустойчивость: основной + запасной relay, автоматическое переключение; падение VELIQ не ломает интернет ПК.
7. Безопасность: засвеченные и тестовые коды отозваны, финальный клубный код выпущен и нигде не опубликован; сертификаты продлеваются автоматически.

   fail-closed защищённых authority, pinning/replay и запрет принудительного restart.

   nonce и один SNI на TCP не доказывают все encrypted HTTP2 authority.
2. Параллельно R4: закончить exact-SHA CI/Setup и лабораторную приёмку на2ПК по
   BETA_ACCEPTANCE.md. Проверить actual ISP/LOCAL/voice, R2 матчи/guards, freeze и
   реальный откат. Код/GUI/службу разных кандидатов не смешивать.
3. R3/R5: владелец проверяет текущую ёмкость/срок кода/сертификаты/standby и решает
   вопросы production. Подготовка Setup не даёт разрешения менять VPS/БД/CA.
4. Только после всех gates PASS —3→5–6ПК под наблюдением. Это ограниченная beta,
   затем недельный R6. R7/40ПК и публичный release отдельно; 7ноября без экспериментов.
