# Реализация и границы проверки

Этот документ описывает компоненты исходного кода. Номер последнего официального установщика указан на [странице загрузки](https://veliqapp.ru/download). Наличие функции в ветке разработки не означает, что она уже установлена на компьютере пользователя.

| Область | Реализовано | Что требует отдельной проверки |
|---|---|---|
| Маршрутизация | Профили, автоматический выбор, прямой и локальный маршруты, закрепление действующих соединений | Доступ к конкретному ресурсу через конкретного провайдера |
| Игры | Определение поддерживаемых процессов и локальные стратегии для новых соединений | Вход на сервер и стабильная игра с измерением задержки, джиттера и потерь; загрузка карты этого не доказывает |
| Защищённый транспорт | QUIC, взаимная проверка сертификатов, подписанные билеты | Доступность и пропускная способность каждого развёрнутого сервера |
| Захват Windows | Интеграция с закреплённым WinDivert, обработка TCP и UDP | Работа на целевой Windows с установленными сетевыми драйверами и защитным ПО |
| Интерфейс | WPF, IPC, состояние службы, управление из трея | Визуальная проверка целевой сборки, масштаба экрана и темы |
| Обновление | Подписанный манифест, проверка пакета, подготовка замены и восстановления | Реальное обновление установленного пакета и восстановление после отказа |
| Подписки | Личный и клубный доступ, привязка компьютеров, серверная проверка прав | Оплата и активация в рабочем окружении после изменения серверной версии |
| Диагностика | Состояние соединений, счётчики и сведения о сбоях | Полнота наблюдения конкретного эпизода; отсутствие записи не доказывает отсутствие сбоя |

## Как читать результаты

Переносимые тесты, сборка для Windows, нативные тесты Windows и проверка на пользовательском ПК — разные уровни проверки. Результат одного уровня не заменяет остальные. Отсутствие входящих пакетов не устанавливает само по себе причину: это может требовать проверки приложения, маршрута, сети и сервера.

Для игровой проверки нужны подтверждённый вход и действующий обмен игровыми данными. Ответ на диагностический запрос, успешный поиск матча и загрузка игрового мира недостаточны.

## Действующие ограничения

- Игровой релей не используется. Его будущая реализация не считается готовой функцией.
- Поддержка IPv6 ограничена; полная защита всех несопоставленных соединений не заявляется.
- Переезд уже открытого соединения на другой маршрут не поддерживается.
- Нельзя обещать снижение задержки на основании измерений до другой цели.
- Необходимо проверять срок действия сертификатов и состояние каждого рабочего сервера отдельно.
- Не следует публиковать исходные сетевые захваты, токены, ключи или коды активации вместе с отчётом об ошибке.

Исторические результаты относятся только к указанным в них сборке и окружению. Они не являются текущим состоянием рабочей инфраструктуры.
