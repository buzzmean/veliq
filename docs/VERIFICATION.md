# Историческая локальная проверка этапов 3–6

Окружение исходного прогона: Linux x64, Go 1.25.1, .NET 8.0.425, PostgreSQL 17, локальный Docker, Chromium и Python Playwright. Это результаты своего этапа разработки, а не приёмка последнего опубликованного пакета.

| Проверка | Зафиксированный результат и границы |
|---|---|
| `go build ./...` | Успешно |
| `go test -race -timeout 120s ./...` | Успешно; подключена тестовая PostgreSQL, проверка API действительно выполнялась |
| `go vet ./...` | Успешно |
| Сборка `GOOS=windows GOARCH=amd64 CGO_ENABLED=0` | Успешно |
| Тесты определения процессов Windows | Собраны; EXE на Linux не запускался |
| `tools/lab` | Настоящий сквозной UDP/TCP-обмен прошёл |
| Короткие проверки случайными входами | `FuzzDecode`, `FuzzReadOpen`, `FuzzFrame`: по 5 секунд и два обработчика; `FuzzTicket`, `FuzzConfig`: по 10 000 входов и один обработчик |
| Серверный стенд Docker Compose | Регистрация, проверка конфигурации, билет устройства и настоящий UDP/TCP через релей прошли |
| Сборка WPF .NET 8 | Без предупреждений и ошибок |
| Переносимый клиент службы | Работа с настоящим демо: четыре измеренных маршрута, три профиля, семь диагностик |
| Chromium | Профиль, реальная остановка релея, диагностика и настройки; ошибок JavaScript не было |
| Наблюдение Compose | Конфигурация проверена; стек Grafana отдельно не запускался |

Тесты охватывали оценку качества, пороги, подтверждение и свежесть, резерв после отказа, закрепление потоков, восстановление пакетов, повторное использование идентичности и конечных точек, настоящий обмен с одноразовым значением, общий бюджет параллельных проб и отмену.

Также проверялись хранение и миграции API, полномочия сообщений состояния, изменение и срок подписи, откат версии и подмена данных той же версии, последняя пригодная конфигурация при отказе сервера, привязка билета, повторы, отзыв, ротация и восстановление защиты после запуска, сохранение профилей и границы IPC.

Результаты не подтверждают нативную отрисовку WPF, работу SCM и именованного канала на Windows, захват драйвером, поведение аварийного завершения, полный IPv6, качество интернета или безопасность и масштабирование рабочей инфраструктуры.

Один параллельный расширенный запуск случайных входов завершился `context deadline exceeded` без сохранённого аварийного примера. Отдельный ограниченный повтор успешно обработал по 10 000 входов билетов и конфигураций. Короткая такая проверка не заменяет аудит безопасности.
