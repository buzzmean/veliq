# Тарифы и обращения на сайте

Тестовые цены: личный аккаунт299 ₽/месяц; клуб199 ₽ за ПК/месяц.
Карточки, справка, пустой каталог ЛК и исходное значение калькулятора клуба согласованы. Это публикация предложения; платёжный каталог control-plane и автопродление не включаются этой правкой.

Клубные CTA ведут на `/clubs#apply`. Остальные кнопки обращения используют `/support#chat` и `data-support-open`: загруженный виджет открывается на текущей странице, иначе обычная ссылка ведёт на страницу помощи и открывает чат после загрузки. Переписка не сбрасывается; нажатие само по себе не создаёт обращение и не отправляет сообщение. `/support#chat-mobile` добавляет редактируемый запрос о мобильной версии только в пустое поле.

Явные адреса электронной почты в реквизитах, правовых документах и резервном noscript остаются доступны. Кнопки обращения и ссылка поддержки в подвале используют онлайн-чат.

Кнопка скачивания называется «Скачать». После получения метаданных она ведёт на проверенный установщик той же версии; при ошибке API — на официальный `/releases/latest/download/VELIQ-Setup.exe`. Предрелизы не продвигаются в публичный релиз этой правкой.

## Публикация

Это дерево содержит основу сайта2bcb6d5 и ранее опубликованные компоненты заявки/виджета9081e570. Оно НЕ является полным снимком работающего сайта: на сервере есть более поздние независимые изменения ЛК и clean URLs.
Для действующего сайта применять только точечные преобразования к свежим серверным файлам с проверкой исходных хешей, закрытой резервной копией и сохранением всех остальных байтов. Не заменять website целиком. Backend, account.js, БД, подписки, TLS, бот и worker не изменяются. Статическая публикация не требует перезапусков служб или ОС.

Проверки: браузерные переходы на странице тарифов, помощи, скачивания, клуба, контактов, главной и ЛК; оба клубных CTA; мобильный запрос и сохранение черновика; прямое скачивание при недоступном API; адаптивность1440/390; отсутствие неявных POST. Изолированный браузер использует тестовые API-ответы, поэтому не заменяет живую приёмку сайта и Telegram.
