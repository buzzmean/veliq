# Закреплённая зависимость WinDivert

Версия: WinDivert 2.2.2-A, x64. [Официальный архив](https://github.com/basil00/WinDivert/releases/download/v2.2.2/WinDivert-2.2.2-A.zip), [исходный проект](https://github.com/basil00/WinDivert).

| Файл | SHA-256 |
|---|---|
| Официальный ZIP | `63cb41763bb4b20f600b6de04e991a9c2be73279e317d4d82f237b150c5f3f15` |
| `x64/WinDivert.dll` | `c1e060ee19444a259b2162f8af0f3fe8c4428a1c6f694dce20de194ac8d7d9a2` |
| `x64/WinDivert64.sys` | `8da085332782708d8767bcace5327a6ec7283c17cfb85e40b03cd2323a90ddc2` |

Контрольные суммы получены из официального релиза, скачанного с проверкой HTTPS. Это закреплённые значения проекта; они не выдаются за отдельно опубликованные автором архива суммы.

`fetch-windivert.ps1` проверяет ZIP до распаковки и оба извлечённых файла, требует доверия Windows к подписи SYS и отказывается заменять существующий каталог зависимости. Установщик и загрузчик службы повторяют проверку хешей. Загрузчик использует абсолютный защищённый каталог и ограниченный поиск DLL.

Официальная DLL не содержит таблицы сертификата Authenticode; официальный SYS содержит встроенную подпись. Требование подписи DLL ранее препятствовало запуску. Корректная проверка — подпись SYS и закреплённые SHA-256 обоих файлов. Разбор PE и проверка хеша на другой ОС не доказывают доверие Windows к подписи и работу захвата.

ZIP, DLL, SYS и другие сторонние бинарники не добавляются в исходный код. Загруженные файлы находятся в исключённых из Git каталогах зависимостей и состояния. Перед распространением выполняются требования лицензии, описанные в [уведомлениях](../third_party/NOTICE.md). Версию и контрольные суммы нельзя менять произвольно.
