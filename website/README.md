# Публичный сайт VELIQ

Актуальные исходники публичных страниц находятся непосредственно в этой папке:
HTML в корне, стили и клиентские сценарии в `assets/`. Сайт статический; сборщик
и установка зависимостей для публикации не требуются.

Тарифная конфигурация: `assets/pricing-policy.json` и её браузерная копия
`assets/pricing-policy.js`. Тексты тарифов в HTML и кабинете должны совпадать с ней.
При изменении JS/CSS обновляйте параметры версии в подключающих страницах.

`design/tools/build-site.py` — исторический генератор первоначального макета.
Он не воспроизводит опубликованные кабинет, чат и текущие документы; не используйте
его для подготовки действующего сайта. Правьте актуальные HTML и ресурсы здесь.

Перед публикацией проверяйте синтаксис изменённых JS, внутренние ссылки, тарифы,
документы, мобильное меню, якорные ссылки и отображение на телефоне и компьютере.
Для локального просмотра нужен HTTP-сервер с поддержкой маршрутов `/privacy`,
`/terms`, `/pricing` и других HTML-страниц без расширения.

Публикация выполняется заменой только изменённых файлов в действующем корне сайта.
Сохраняйте исходные права, резервную копию и контрольные суммы; перед записью
сверяйте исходное состояние, чтобы не перезаписать параллельные изменения.
Изменения HTML/CSS/JS не требуют перезапуска серверных служб.
